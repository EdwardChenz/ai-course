- **概念** *（必需）*：learning-graph.csv 中的行数

- **MicroSim** *（推荐）*：docs/sims/ 下包含 index.md 文件的目录
- **故事** *（可选）*：docs/stories/ 下包含 index.md 文件的目录
- **章末测验** *（推荐）*：包含 quiz.md 文件的章节（测验题总数见备注列）
- **章节参考资料** *（推荐）*：包含 references.md 文件的章节（参考资料条目总数见备注列）
- **术语表条目** *（推荐）*：glossary.md 中的 H4 标题
- **常见问题** *（推荐）*：faq.md 中的 H3 标题
- **字数** *（必需）*：面向学生的 markdown 文件中的全部字数（不含代码块与 URL）
- **吉祥物** *（可选）*：docs/img/mascot/ 下的图片文件（姿态）
- **附录** *（可选）*：appendices/ 目录下的页面（不含 index.md）
- **开发阶段** *（必需）*：mkdocs.yml（或 course-description.md）中的 `development_stage` 值；若缺失则显示“未指定”
- **实验** *（可选）*：docs/labs/ 下包含 index.md 文件的动手实验目录

### 内容指标

- **图表**：以 '#### Diagram:' 开头的 H4 标题
- **公式**：使用 $ 和 $$ 分隔符的 LaTeX 表达式
- **总字数**：markdown 文件中的全部字数（不含代码块与 URL）
- **链接**：markdown 格式的链接 `[text](url)`
- **等效页数**：按每页 250 字 + 每图 0.25 页 + 每个 MicroSim 0.5 页折算

### 列说明

- **全部内容**：包含全部面向学生的内容（章节、术语表、常见问题、MicroSim 等），但不含管理性目录
