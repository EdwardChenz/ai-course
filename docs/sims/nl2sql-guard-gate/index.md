## 描述

顶部是六条安全红线（只读账号、单条 SELECT 语句白名单、超时 30 秒、行数上限 10,000、扫描字节上限 50 GB、并发上限 4）与人工确认的四个触发条件。下面是六条请求的六项属性表。每条请求要提交两项判定——放行还是拦截，以及越界的是哪几条红线（可多选）；最后再判一次哪条请求需要人工确认。共 13 次提交，全部填齐后统一揭晓。

- **判定规则**：六条红线的或运算，任一条越界即拦截；边界按开区间处理，恰好等于阈值判不越界
- **计分**：满分 13 分，13 分视为掌握，容差为 0 条

## 学习目标

学习者将对六条自然语言取数请求逐条判定放行或拦截，并在放行的请求中指出它通过了哪几道关、为什么需要或不需要人工确认。

**Bloom 层级**：Evaluate（评价）

## 使用建议

1. 先读六条红线的阈值，注意三条阈值都按开区间处理。
2. 逐条选放行或拦截，再勾选越界的红线；全不勾即视为无越界。
3. 最后选出需要人工确认的那一条，13 项填齐后提交揭晓。
4. 揭晓后对照每条请求的红线核对表，看清是哪一条数值越界。
