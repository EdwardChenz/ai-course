## 描述

拖动重试次数、开关熔断联动，实时读出总耗时上限与最终成功率，并在 5000 毫秒用户等待预算下完成三道手写挑战题。

- 最终成功率 = 1 − 0.30^(k+1)；总耗时上限 = 调用次数 × 800 毫秒 + 退避等待之和。

## 学习目标

学习者将调节重试次数与熔断联动开关，算出四种方案的总耗时上限与最终成功率，并在 5000 毫秒预算下选出方案 B。三项判定（方案 B、3400 毫秒、0.910）全部一致（容差 ±0.001）算掌握。

**Bloom 层级**：Evaluate（评价）

## 使用建议

1. 先把 k 从 0 拖到 3，注意成功率每次只涨一点而耗时每次多跳一截。
2. 关掉再打开熔断联动，观察总耗时上限骤降到 800 毫秒：熔断省的是等待，不是成功率。
3. 依次作答三题，每题两次机会；最后一题结束后展示四个方案的完整推导。
