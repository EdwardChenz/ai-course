## 描述

六道真实查询在「仅用原查询」与「假文档替换原查询」两种做法下的前 20 名命中数对比。增益列在提交前保持空白：先猜哪一道会倒亏，再选出双路融合的工程修法。

- 增益 = 假文档替换后命中数 − 仅原查询命中数；增益 ≤ 0 判为变差。

## 学习目标

学习者将比较六道查询在两种做法下的前 20 名命中数，并选出唯一出现负增益的查询（序号 5，增益 -5），且能说出「假文档只走稠密路、原查询保留在稀疏路做双路融合」这一修法。序号判定与修法判定两项都满足算掌握。

**Bloom 层级**：Analyze（分析）

## 使用建议

1. 六行查询与两组命中数直接给出，增益列留空，先在纸面上算一遍 17 − 11、16 − 12 这类差值。
2. 第 1 题在下方面板填入序号，整数精确匹配，两次机会。
3. 第 2 题用下拉框选工程修法；错答会提示「假文档会编造编号」，并要求指出被带偏的是哪一路。
4. 注意规格块正文的合计「86 / 14.3」与其数据表不一致，本模拟器按表逐行求和给出 96 / 16.0 并在画面上标注。
