## 描述

给学习者一张四模型四维度的评分卡。权重固定为任务实测效果 0.4、成本 0.2、延迟 0.2、工程约束 0.2，各维度 0~5 分、5 分最好；总分按加权求和保留 1 位小数，填写过程中实时显示本地算出的总分，锁定提交后才与标准总分逐格比对并标出「推荐」。

- **总分** = 0.4×效果 + 0.2×成本 + 0.2×延迟 + 0.2×工程约束

## 学习目标

学习者将按四项维度（任务实测效果、成本、TTFT P95、工程约束）为四个候选模型加权打分，并选出总分最高者。

**Bloom 层级**：Evaluate（评价）

## 使用建议

1. 先逐格给 A、B、C、D 打分，观察加权总分是否随改动变化。
2. 点「锁定打分并提交」，四张卡片会展开标准总分与反馈原因，最高分并列者同时标为「推荐」。
3. 在「推荐结论」里选出你的结论并提交。注意正确答案是分工而不是强行单选。
4. 答错时对照反馈文案，指出贡献最大的两个维度。
