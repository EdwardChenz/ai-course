## 描述

情境、任务、行动、结果四维各 0 到 3 分的量表与三段讲述稿摘要。为每段填入四维分数、提交达标判定与最弱维度，再对照标准答案。

- 总分 = 情境 + 任务 + 行动 + 结果（满分 12）；≥ 9 直接进作品集，7 到 8 补一项即可，≤ 6 重写。

## 学习目标

学习者将按情境、任务、行动、结果四维各 0 到 3 分为三段讲述稿打分，判定每段是否达到总分 9 分的作品集门槛，并指出待补强一段中最弱的一维。三段总分计算正确、达标判定与 Content 表一致、且最弱维度判断正确三项全部命中时算掌握。

**Bloom 层级**：Evaluate（评价）

## 使用建议

1. 先读四维量表，注意 3 分档都要求可验证数字与取舍依据。
2. 为讲述稿 1 到 3 依次填入四维分数（总分实时相加）、选择达标判定与最弱维度，点「提交打分与判定」。
3. 关键观察：编号 3 的行动维拿满 3 分却仍不完美，差别全在结果维的口径与缺口。
