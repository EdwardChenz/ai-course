## 描述

八条需求纵向排列，每条给出一个路由下拉框和三个判定依据复选框。锁定前不显示任何标准答案；八条全部锁定后一次性揭晓，逐条给出「正确，序号 n 应路由到 X」或错答反馈，并显示每条需求在三个判定条件上的命中情况（规格只为序号 1、5、7 给出了标准命中数）。

- 路由取值限定为六项：直接调用、内部 HTTP 适配、框架内交接、MCP 向下、A2A 向右、A2A 加契约加审计
- 得分 = 判定正确的条数，满分 8 分；>= 7 分视为掌握

## 学习目标

学习者将逐条判定八个需求的协议路由（直接调用、内部 HTTP 适配、框架内交接、MCP 向下、A2A 向右、A2A 加契约加审计），判定条件是八条全部与 Content 表一致且能对任意一条给出判定所依据的三个条件中至少两个。

**Bloom 层级**：Evaluate（评价）

## 使用建议

1. 先读顶部三条判定条件，再逐条选路由并勾选依据。
2. 八条全部锁定后点「锁定八条路由并提交」，得分会立即出现。
3. 特别回看序号 5 与序号 7：这两条的正确答案都是「不上 A2A」。
4. 全部判定结束后用一句话解释序号 5 为什么不选 A2A。
