## 描述

日均 12000 次请求、有效问答完成率 84% 下，按每档有效样本 ≥ 500、必须经过 50% 档、五个工作日内到达 100% 三条硬约束，逐套评判四套灰度放量方案并选出唯一可执行的一套。

- 有效样本 = round(12000 × 比例 × 0.84)；合格 = 全部档位有效样本 ≥ 500 且序列含 50% 档且天数 ≤ 5。

## 学习目标

学习者将按三条硬约束评判四套灰度放量的合格性，并选出唯一可执行的一套。四套判定与 Content 表全部一致且最终选择为方案 2 时算掌握。

**Bloom 层级**：Evaluate（评价）

## 使用建议

1. 先核对固定输入与各档有效样本：5% → 504、10% → 1008、20% → 2016、30% → 3024、50% → 5040、100% → 10080。
2. 逐套提交合格 / 不合格判定，再提交最终方案；判定锁定后才揭晓被否的具体约束。
3. 关键观察：方案 3 五档样本全部达标仍被否（缺 50% 档），方案 4 档位齐全却因 6 天超工期出局。
