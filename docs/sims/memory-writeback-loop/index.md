## 描述

四个阶段横向排在内容区顶部，下面是四条候选事实的证据命中、稳定性、置信度与目标画像字段。置信度阈值滑块（0.50~0.95，步长 0.05，默认 0.60）实时重算丢弃条数与写入条数；四道题逐题提交，每题两次机会，提交后立即揭晓落点结果。

- **丢弃条件**：`stability == volatile` 且 `confidence < 阈值`，两条同时成立才丢弃
- **写入长期记忆的条数** = 总候选数 − 丢弃条数

## 学习目标

学习者将把一段 12 轮会话按「证据校验 → 稳定性判定 → 落点路由 → 显式覆盖」走一遍，并回答四个判定：哪条候选被丢弃、几条候选写入长期记忆、哪两个画像字段被覆盖更新、序号 4 为何不进画像。

**Bloom 层级**：Analyze（分析）

## 使用建议

1. 先看四条候选的置信度，注意序号 3 是唯一 volatile 的一条。
2. 逐题写下判定并提交，第一次答错会先展示该候选的整行数据再给反馈。
3. 把阈值从 0.60 拖到 0.50，观察留存条数从 3 变成 4——阈值是唯一的旋钮而其他条件不变。
