## 描述

拖动半衰参数与回填阈值，观察六条记忆的留存曲线如何分家——噪声类最先跌破阈值，硬约束那条纹丝不动——再完成三道手写挑战题。

- S = min(1.0, w × R × e^(−Δt/τ) × (1 + ln(1+n)))，硬约束的衰减项固定取 1。

## 学习目标

学习者将调节半衰参数与回填阈值，观察六条记忆的留存分数变化，并回答三个判定（默认参数下 3 条被归档、τ 调到 90 天后序号 2 为 0.6150、硬约束的衰减项取 1 因而只有显式覆盖能作废）。三题全部命中算掌握，容差 ±0.001。

**Bloom 层级**：Analyze（分析）

## 使用建议

1. 先把 τ 从 15 拖到 365，观察六条曲线分家；硬约束那条恒为 1.0000。
2. 再把阈值从 0.02 拖到 0.60，归档条数从 0 涨到 5——阈值是唯一的开关。
3. 依次作答三题，每题两次机会；第 3 题必须同时点出「衰减项取 1」与「只有显式覆盖能作废」两个要点。
