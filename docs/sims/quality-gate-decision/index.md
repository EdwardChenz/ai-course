## 描述

四道门禁与六种候选版本配置。逐条判合格或不合格，再提交最终发布版本，全部锁定后揭晓每种配置被卡住的具体门禁。

- 合格 = 答案正确率 ≥ 0.85 且 幻觉率 ≤ 0.05 且 P95 ≤ 3.00 秒且 成本 ≤ 0.030 元。

## 学习目标

学习者将对六个候选版本的四项指标逐条判定是否放行，并在四条门禁约束下选出唯一可发布版本。六条判定与 Content 表的「合格判定」列全部一致，且最终选择为序号 2（v1.3.0 全量配置）时算掌握。

**Bloom 层级**：Evaluate（评价）

## 使用建议

1. 先记住四条门禁：答案正确率 ≥ 0.85、幻觉率 ≤ 0.05、P95 ≤ 3.00 秒、成本 ≤ 0.030 元。
2. 逐条提交合格 / 不合格判定，再提交最终发布版本；揭晓时逐行标出被卡住的门禁。
3. 关键观察：序号 6 的幻觉率 0.03 优于合格配置却仍被否；序号 5 只解决延迟不解决质量。
