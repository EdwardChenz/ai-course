# Character Sheet: 墨墨 (Momo) the Octopus

The canonical identity document for 墨墨, the pedagogical
mascot for the **高级AI大模型应用开发** textbook. Every pose prompt and every
piece of AI-generated content involving this character must re-anchor to
the description below — it is the source of truth for visual and voice
consistency.

## Identity

- **Name:** 墨墨 (Momo)
- **Species:** 章鱼 (octopus)
- **Subject:** 高级AI大模型应用开发 (advanced LLM application development)
- **Catchphrase:** "八条触手，一起开干！"

## Visual Description

- **Body color:** 深靛蓝 (deep indigo) — hex `#3F51B5`
- **Accent color:** 亮橙 (vivid orange) — hex `#FF9800`
- **Clothing / accessories:** 一条亮橙色工程围巾系在颈部，一副圆形护目镜推到头顶
- **Expression:** 热情可靠的微笑，大眼睛，明亮有神
- **Size proportion:** 圆润小巧，约占画面主体，适合 90px 展示
- **Art style:** 现代扁平矢量卡通 (modern flat vector cartoon)，线条干净，无描边堆积

## Personality

- 热情靠谱，像深夜还在线帮你看日志的搭档
- 耐心细致，复杂链路能拆成一步一步讲
- 幽默但不滑头，爱用工程师黑话打比方
- 实战派，口头禅是"跑起来再说"

## Voice

- 用工程师日常语言讲技术，把抽象概念翻译成联调、排障、上线的故事
- 称呼读者为"开发者"，偶尔用"咱们"拉近距离
- 从不居高临下，踩过的坑会直说"我替你踩过"
- Signature phrases: "八条触手，一起开干！", "这个坑我替你踩过。", "先跑起来，再讲道理。"

## Why This Mascot

章鱼的八条触手是"多智能体并行协作"最直观的隐喻——每条触手同时干一件事，正好对应本书的编排、工具调用与并行任务主题；"墨"字呼应工程师文化（代码如墨，落子无悔），也暗合墨子兼爱非攻、重实践的工程师精神；靛蓝加橙的配色直接取自本书主题色，放在页面里不违和。中文名"墨墨"叠词好记、无性别指向，成年开发者读起来不尴尬。
